# Software & Application Access

## Category
software

## Quick Answer
To request access to new software or an internal tool, submit a request at tools.company.com with the tool name, business justification, and your manager's email for approval. Standard hardware requests (laptop, monitor, keyboard) take 5-7 business days after approval.

## Common Problems & Solutions

### Requesting Access to New Software or Internal Tool
**Cause:** Employee needs a tool that is not currently provisioned to their account.
**Solution:**
1. Go to tools.company.com.
2. Select the tool name from the catalog, or describe it if not listed.
3. Provide a business justification.
4. Add your manager's email for approval.
5. Access is typically granted after manager approval is completed.

### Software Not Available in Software Center
**Cause:** The application is not pre-approved for self-service installation.
**Solution:**
1. Check the Software Center in the Start Menu for pre-approved installs first.
2. If not available there, raise a request at tools.company.com under category "Software Installation Request".

### Requesting New Hardware
**Cause:** Need for a monitor, keyboard, headset, or laptop replacement.
**Solution:**
1. Submit a request via the IT portal at tools.company.com under category "Hardware Request".
2. Include business justification and manager email for approval.
3. Standard delivery takes 5 to 7 business days after approval.

### Printer Setup
**Cause:** New device or first-time office printer configuration.
**Solution:**
1. Go to Settings, then Printers and Scanners.
2. Click Add Printer and select your floor printer from the list.
3. If not visible, use the IP address provided on the printer label.
4. Personal printing is not allowed on office printers.
5. For persistent printing issues, contact IT helpdesk.

### Access Request Pending Too Long
**Cause:** Manager approval delay, or the request is stuck in the approval queue.
**Solution:**
1. Check the request status under My Requests on the portal.
2. Follow up directly with your manager if approval is pending beyond 2-3 business days.
3. If the request shows approved but access is still not working, contact IT with the request ID.

## Escalation
Contact IT Helpdesk if:
- A request remains pending significantly beyond the normal approval timeframe.
- Access was approved but is still not functioning.
- Hardware delivery is delayed beyond 7 business days after approval.
